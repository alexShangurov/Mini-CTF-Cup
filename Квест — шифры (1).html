Каждый ответ — флаг

Русские ответы записываем как флаг{...}, английские — как flag{...}. Используй фигурные скобки. Между словами внутри — подчёркивания, без пробелов.

Если получилось слово «дом»: флаг{дом}
Если получилось «доброе утро»: флаг{доброе_утро}
Если получилось «hello»: flag{hello}

Если после расшифровки уже получился полный флаг, не добавляй вторую оболочку. Регистр при сдаче не важен. Буквы русского «флаг» и английского «flag» не смешиваем.

В Google Форме выбери свою команду и номер задания, затем отправь полный флаг. Неверную попытку можно исправить новой отправкой; повтор верного ответа баллы не добавляет. Ссылку на форму выдаёт ведущий.

Пояснения: от простого к сложному

01 / ПАМЯТКА

Кодирование, шифрование, сокрытие

Кодирование — представить информацию по другим правилам, чтобы хранить или передавать её. Например, букву заменить числом. Правила могут знать все.

Шифрование — скрыть содержание. Алгоритм задаёт способ, ключ — его настройку. У Цезаря ключом будет величина сдвига.

Сокрытие — спрятать сообщение внутри другого текста. Пример — акростих. Внешне перед нами обычные строки, но у них есть второй смысл.

Hex и Base64 не требуют секретного ключа. Они сами по себе не защищают данные от чтения.

02 / ПАМЯТКА

Зеркало

Всю строку записывают в обратном порядке: последний символ становится первым. Меняются местами и буквы, и знаки.

Исходное слово: ДОМ
Зеркальная запись: МОД
Читаем справа налево: ДОМ
  1. Начни с последнего символа.
  2. Двигайся к первому, сохраняя каждый символ.
  3. Не потеряй скобки, если в сообщении есть флаг.
03 / ПАМЯТКА

Номера букв

Заменяем букву её порядковым номером в выбранном алфавите. В нашем квесте 32 буквы, без Ё: А = 1, Б = 2, … Я = 32.

ДОМ → 5 15 13
5 → Д, 15 → О, 13 → М

Для расшифровки найди каждый номер в таблице и выпиши буквы в том же порядке. Пробел разделяет числа, а не обязательно слова исходного сообщения.

Номер буквы в нашей таблице — не код ASCII. Это две разные системы.

04 / ПАМЯТКА

Двоичные номера букв

В десятичной записи используются цифры 0–9, в двоичной — только 0 и 1. Значение единицы зависит от её места. Веса разрядов справа налево: 1, 2, 4, 8, 16, 32.

Разряды: 16  8  4  2  1
Число:    0  1  0  0  1
01001 = 8 + 1 = 9 → И
  1. Раздели сообщение на группы по пробелам.
  2. В каждой группе сложи веса разрядов с единицей.
  3. Полученное число найди в пронумерованном алфавите.

Нули слева значения не меняют: 00101 = 101 = 5. Для номера 32 требуется шесть разрядов: 100000.

Двоичная запись может представлять и номер буквы, и байт, и другое число. Всегда учитывай условие задания.

05 / ПАМЯТКА

Азбука Морзе

Каждой букве соответствует последовательность коротких и длинных сигналов — точек и тире.

Д → -..
О → ---
М → --
ДОМ → -.. / --- / --
  1. Посмотри, каким знаком разделены буквы.
  2. Найди каждую группу целиком в таблице.
  3. Запиши найденные буквы подряд.

В нашем задании косая черта / разделяет буквы. В других записях она может разделять слова — единого оформления для всех задач нет.

06 / ПАМЯТКА

Атбаш — алфавит наоборот

Пишем алфавит в обычном порядке, под ним — в обратном. Каждую букву меняем на ту, что стоит под ней. Порядок символов в сообщении не меняем.

А ↔ Я, Б ↔ Ю, В ↔ Э …
ДОМ → ЫСТ
Ы → Д, С → О, Т → М

Одна и та же таблица подходит и для шифрования, и для расшифровки.

Зеркало переставляет символы. Атбаш заменяет символы. Это не одно и то же.

07 / ПАМЯТКА

Цезарь — буквы со сдвигом

Для каждой буквы отсчитываем одно и то же число позиций вправо. Это число — ключ. Дойдя до Я, продолжаем с А.

КОТ → ЛПУ  при сдвиге +1
КОТ → МРФ  при сдвиге +2
КОТ → НСХ  при сдвиге +3
  1. Уточни алфавит: русский или латинский, есть ли Ё.
  2. Если при шифровании двигались вправо на 3, при чтении двигайся влево на 3.
  3. Пробелы, подчёркивания и скобки оставляй как есть.
При +3: Ю → Б
Обратно: Б → Ю

Если ключ неизвестен, проверяй разные сдвиги и ищи осмысленный результат. Один найденный сдвиг должен подходить ко всему сообщению.

Цезарь удобен для обучения, но для современных секретов слишком прост: сдвиги легко перебрать.

08 / ПАМЯТКА

Акростих

Сообщение образуют первые буквы строк. Не переставляй строки и не убирай переносы.

Дом засыпает.
Облако тает.
Месяц сияет.
  1. Возьми Д из первой строки.
  2. Возьми О из второй и М из третьей.
  3. Прочитай ДОМ.

Так смысл можно скрыть в обычном стихотворении или тексте.

09 / ПАМЯТКА

ASCII

ASCII — таблица соответствия символов и числовых кодов. Например, A = 65, B = 66. Заглавные и строчные буквы имеют разные коды. Русских букв в ASCII нет.

CAT → 67 65 84
67 → C, 65 → A, 84 → T

Числа можно читать по таблице. Для длинной последовательности в CyberChef есть From Decimal: она преобразует десятичные значения байтов в текст. Если значения разделены пробелами, выбирай разделитель Space.

Для русского текста используются другие кодировки, например UTF-8. Не любая буква занимает один байт.

10 / ПАМЯТКА

Hex: шестнадцатеричная запись

В Hex шестнадцать цифр: 0–9, затем A, B, C, D, E, F со значениями 10–15. Правый разряд — единицы, следующий — шестнадцатки.

Hex 41 = 4 × 16 + 1 = 65
ASCII 65 → A
CAT → 43 41 54
  1. Вставь последовательность в Input.
  2. Выбери From Hex и разделитель Space, если нужны пробелы.
  3. Посмотри Output: это может быть текст или следующий слой.

Байт удобно записывать двумя Hex-цифрами. Запись 41 — не «сорок один», если условие говорит о Hex.

11 / ПАМЯТКА

Base64

Base64 представляет байты с помощью 64 символов: A–Z, a–z, 0–9, +, /. Иногда на конце добавляется =. Декодировать можно без ключа.

CAT → Q0FU
Q0FU → CAT
  1. Скопируй строку полностью, сохранив регистр и =.
  2. В CyberChef выбери From Base64.
  3. Проверь, получился текст или ещё один слой.

Не нужно считать Base64 вручную. Важно отличать этот формат от шифра и понимать, какой инструмент применяешь.

По виду строки можно предположить формат, но не доказать его. Проверяй результат преобразования.

12 / ПАМЯТКА

Матрёшка: несколько слоёв

Одно преобразование применяют к результату другого. Раскрывать нужно в обратном порядке.

Создание: CAT → зеркало → TAC → Hex → 54 41 43
Чтение:   54 41 43 → From Hex → TAC → зеркало → CAT

После каждого шага записывай, что получилось. Набор чисел или новая закодированная строка могут быть правильным промежуточным результатом.

В CyberChef операции в Recipe выполняются сверху вниз. Добавляй их по одной, чтобы видеть, на каком шаге возникла ошибка.

Как работать в CyberChef

Открыть CyberChef ↗
  1. Скопируй сообщение в Input.
  2. В поиске Operations найди нужную операцию и перетащи её в Recipe.
  3. Посмотри Output. Если Auto Bake выключен, нажми Bake.
  4. Для следующего слоя добавь ещё одну операцию в рецепт. Результат предыдущей станет её входом.

Полезные названия: From Base64, From Hex, From Decimal, From Binary, Reverse. Операция ROT13 позволяет менять величину сдвига латинских букв через Amount.

Для чисел, разделённых пробелами, выбери разделитель Space. Русские шифры решаем по алфавиту на бумаге.

По правилам квеста не используем Magic и автоматический подбор рецепта. Нужно самим выбрать способы и объяснить решение.
